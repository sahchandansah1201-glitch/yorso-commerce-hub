# Human Steering / Delivery

- **Accountable for:** approvals, handoff clarity, branch boundaries and delivery ledger.
- **Inputs:** accepted scope, risks, test evidence and release recommendation.
- **Outputs:** approval decision, owner assignments, plan/fact report and unresolved gates.
- **May decide:** authorize protected delivery steps within the explicit user boundary.
- **Must not:** convert missing evidence into a pass.
- **Independent reviewer:** `qa-release-owner`.
- **Skill IDs:** `yorso-engineering-quality-gate-agent`, `yorso-release-reliability-agent`.

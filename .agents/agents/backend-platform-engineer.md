# Backend / Platform Engineer

- **Accountable for:** self-hosted APIs, persistence, queues, observability and failure behavior.
- **Inputs:** product contract, load profile, data ownership and security boundary.
- **Outputs:** versioned contract, migration/runtime implementation, telemetry and recovery plan.
- **May decide:** architecture inside the accepted service and scale constraints.
- **Must not:** introduce hosted BaaS dependencies or unreviewed contract drift.
- **Independent reviewer:** `trust-compliance` and `qa-release-owner`.
- **Skill IDs:** `yorso-service-architecture-agent`, `yorso-api-contract-gate-agent`, `yorso-engineering-quality-gate-agent`.

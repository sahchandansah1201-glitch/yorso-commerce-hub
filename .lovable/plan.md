# «Оставить запрос» в каталоге /offers: дизайн для внедрения

Это дизайн для локальной работы Codex. Я не открывал ваш сайт и ничего не проверял.

## 1. Каталог: что меняется
- Убрать видимую строку «Моя закупка». Данные (выбор, сравнение, запросы поставщику) не трогать.
- Панель над результатами: `[Поиск ......] [Фильтры] [Оставить запрос]`.
  - Кнопка: `Button variant="outline"`, иконка `MessageSquarePlus` 16px + текст, `h-11 sm:h-10 min-w-11`.
  - 390px: поиск на всю ширину в первой строке; во второй строке «Фильтры» и «Оставить запрос» по `flex-1`.
- Приглашение (один раз за сессию, только после успешного поиска с 0 результатов) — строка в пустом списке, без рамки-карточки:
  `text-sm text-muted-foreground` «Не нашли нужный товар?» + `Button variant="link"` «Оставьте запрос» + `Button variant="ghost" size="icon" aria-label="Скрыть"`. Не показывать при загрузке, ошибке, запасных данных. Фокус не переносить.

## 2. Панель формы
- Компьютер и планшет (≥768): `Sheet side="right"`, `w-full sm:max-w-[440px]`.
- Телефон (<768): та же форма в `Drawer`, `max-h-[90dvh]`, прокрутка внутри, кнопки внизу `sticky bottom-0 bg-background border-t pb-[env(safe-area-inset-bottom)]`.
- Порядок сверху вниз, без вложенных карточек, `space-y-4`:
  1. Заголовок «Запрос на товар» + строка `text-sm text-muted-foreground` «Запрос получит команда YORSO. Это не заказ.»
  2. «Что нужно купить?» * — `Textarea rows=4`, пример в placeholder.
  3. «Страна доставки» * — общий поиск по странам из профиля аккаунта. Под полем: «Из профиля компании. Можно изменить.» (только если подставлено).
  4. `Collapsible` «Добавить детали»: Количество + единица (т, кг, коробки) в одной строке; Город или порт; Дата.
  5. Контакт: для вошедшего — одна строка `text-sm` «Ответ придёт: buyer@… (из профиля)». Для гостя — блок «Войдите, чтобы отправить запрос» + кнопка «Войти»; черновик сохраняется.
  6. Подвал: `[Отмена ghost] [Отправить запрос primary]`, оба `h-11`.
- Ошибки: под полем `text-xs text-destructive`, `aria-invalid`, `aria-describedby`; при отправке фокус на первое поле с ошибкой.
- Закрытие (Esc, крестик, назад): фокус возвращается на кнопку, которая открыла форму.

## 3. Страна доставки: правило
Ручной или восстановленный выбор > страна из профиля текущей компании (только если форма новая и поле не трогали) > пусто. Поздний ответ профиля, повторное открытие и смена языка не меняют выбор. Профиль не изменяется. Хранить код страны, показывать название.

## 4. Состояния (строка над подвалом, `role="status"`)
| Состояние | Вид |
|---|---|
| Черновик | `text-xs text-muted-foreground` «Черновик сохранён на этом устройстве.» |
| Нет сети | «Нет сети. Черновик сохранён. Отправьте позже.» Кнопка активна. |
| Отправка | Кнопка disabled + спиннер, «Отправляем…» |
| Ошибка | `text-destructive` «Запрос не отправлен. Попробуйте ещё раз.» |
| Неизвестный результат | «Проверяем, принят ли запрос. Не отправляйте повторно.» Повтор с тем же ключом. |
| Принят | Форма заменяется на квитанцию: «Запрос принят. Номер Q-1042.» + ссылка «Мои запросы» + «Закрыть». |
Пока нет настоящего сервера, кнопка «Отправить» не показывает «Принят». Вместо этого: «Отправка пока недоступна. Черновик сохранён.»

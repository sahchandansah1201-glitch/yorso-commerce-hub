# Карточка контакта: несколько телефонов и почт + каналы связи

Только анализ. Файлы кода не менялись. Доработка планируется внутри существующей карточки контакта в YORSO, без отдельного макета и без нового названия системы в интерфейсе.

## Краткий UX-обзор решения

**Что поддерживаю**

- Группы «Телефоны» и «Почты» вместо отдельных высоких строк — это снимает главную проблему текущей карточки.
- Основное значение первым, с короткой подписью «Основной». Один основной телефон и одна основная почта.
- Действия рядом со значением: у телефона «Позвонить» + «Скопировать», у почты «Написать» + «Скопировать». Значение и его кнопки — в одной строке, без выноса в конец блока.
- Каналы (WhatsApp / Telegram / WeChat) — как сохранённые данные, а не как активные отправки. Кнопка «Связаться» открывает окно со списком сохранённых каналов и копированием.

**Что стоит поправить в задумке**

- «Связаться» не должна дублировать «Позвонить» и «Написать». Пусть в окне будут только каналы и сохранённые значения, а звонок и почта остаются кнопками у своих строк.
- Пока каналы не подключены, в окне не должно быть кнопок «Отправить», «Открыть чат», счётчиков и любой истории. Только значение, копирование и подпись состояния.
- В просмотре не показываем пустые каналы отдельными строками с «Не указано» — в этом блоке пустые скрываем, а в форме редактирования поля есть всегда.
- Группа больше 3 значений в просмотре сворачивается: «Ещё 2» / раскрытие. Иначе карточка снова вытягивается.
- Добавление строки — компактная текстовая кнопка «Добавить телефон» / «Добавить почту» под группой, только в режиме редактирования. Удаление — иконка с подписью для чтения с экрана, ≥44×44 px на телефоне.
- Международный номер: храним и показываем ровно то, что ввёл пользователь; визуально разделяем группы цифр только при показе, страну не угадываем и код не подставляем. Копирование даёт номер без пробелов, чтобы вставка в набор работала.
- Плотность: строка значения 40–44 px, вертикальный отступ между строками группы 4–6 px, между группами — прежний отступ разделов.

**Ответственный сотрудник**

- Поле «Менеджер» = ответственный сотрудник компании. Менять может только владелец или администратор; менеджер видит поле как текст. Смысл поля стоит подписать одной строкой-подсказкой, иначе его путают с автором записи.

## Три проверяемых риска

1. **Потеря или искажение цифр номера.** Проверка: ввести номера в разных форматах (с плюсом, с пробелами, со скобками, 8–15 цифр), сохранить, перезайти в карточку и сравнить набор цифр до и после; скопированное значение должно содержать те же цифры без пробелов.
2. **Ложное ощущение отправки.** Проверка: открыть окно «Связаться» во всех трёх языках и убедиться, что в разметке нет кнопок отправки/открытия чата, нет истории сообщений и есть явное состояние «Канал не подключён»; поиск по интерфейсу не должен находить слов «отправлено», «доставлено».
3. **Разрастание карточки и переполнение на 390 px.** Проверка: контакт с 4 телефонами, 3 почтами и всеми каналами при ширине 390 px — нет горизонтальной прокрутки, группы сворачиваются, все кнопки ≥44×44 px, порядок обхода клавиатурой по строке: значение → копировать → позвонить → удалить.

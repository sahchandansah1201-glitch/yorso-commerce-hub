# Консультация: окно выбора района ФАО в карточке товара

Только рекомендации. Файлы проекта не менялись, локальный стенд я не открывал. Описание текущего состояния взято из вашего сообщения.

## 1. Компоновка desktop (окно ≥ 1024px)

```text
┌ Район ФАО ───────────────────────────────────────── [×] ┐  шапка 56px, фиксирована
│ [Поиск: номер или название…]   Морские | Внутренние     │  панель 52px
├───────────────────────────────────────────┬─────────────┤
│                                           │ 18 Арктика  │
│            КАРТА (вся высота)             │ 21 СЗ Атл.  │  список 320px,
│     object-fit: contain, по центру        │ 27 СВ Атл. ●│  своя прокрутка
│                                           │ ...         │
│                                           │ Внутренние  │
│ [+][−][⤢]                    легенда      │ 01 Африка   │
├───────────────────────────────────────────┴─────────────┤
│ Выбрано: 27 · Северо-Восточная Атлантика  [Отмена][Выбрать] │  футер 64px, фиксирован
└─────────────────────────────────────────────────────────┘
```
- Окно: `width: min(1200px, 96vw)`, `height: min(820px, 92dvh)`, сетка `grid-rows: auto auto 1fr auto`.
- Тело: `grid-cols: 1fr 320px`, `min-h-0` у обеих колонок. Карта заполняет ячейку целиком: SVG с `preserveAspectRatio="xMidYMid meet"`, `width/height 100%`. Фиксированное соотношение 2:1 убрать — тогда пустая область под картой исчезает.
- Фон ячейки карты = цвет «океана» (тот же, что в SVG), поэтому полосы от `meet` не выглядят пустотой.
- Масштаб: кнопки + / − / «Вся карта» (44px) и колесо мыши; при выборе в списке карта плавно центрируется на районе (без анимации при `prefers-reduced-motion`).

## 2. Компоновка mobile (< 768px)

```text
┌ Район ФАО                 [×] ┐
│ [Поиск…]                       │
│ [Список] [Карта]  (сегменты)   │
├────────────────────────────────┤
│ список на всю высоту или       │
│ карта на всю высоту            │
├────────────────────────────────┤
│ Выбрано: 27      [Выбрать]     │
└────────────────────────────────┘
```
- Полноэкранный слой `100dvh`, по умолчанию открыт «Список» (быстрее для 27 строк), «Карта» — вторая вкладка с тем же выбором.
- Тап по району на карте выбирает его и показывает плашку внизу «27 · Северо-Восточная Атлантика»; переключаться на список не нужно.
- 768–1023px: карта сверху `45dvh`, список снизу с прокруткой.

## 3. Состояния выбора и наведения (только стили)
Сейчас: оранжевый текст на оранжевом фоне, контраст низкий. Предлагаю:
- **Строка списка выбрана**: фон `primary/10`, слева полоса 3px `primary`, текст `foreground` полужирный, справа галочка (Lucide Check) `primary`; `aria-selected="true"`. Контраст текста к фону ≥ 7:1.
- **Наведение и активная строка с клавиатуры**: фон `muted`, текст `foreground`. Голубой для активной опции — как в принятом CrmSelect, чтобы активная опция отличалась от выбранной.
- **Фокус**: кольцо 2px `ring` (оранжевое) со смещением внутрь.
- **Карта, район выбран**: заливка `primary` 35%, обводка 2px `primary` поверх всех соседей (выбранный полигон рисуется последним), номер района на карте полужирный.
- **Карта, наведение**: заливка `navy` 15%, обводка 1.5px `navy`; связано со списком — наведение на строку подсвечивает полигон и наоборот.
- **Остальные районы**: заливка `card`, граница 0.75px `border`, номера `muted-foreground`.
- Состояние передаётся не только цветом: галочка, полужирный текст и толщина обводки.

## 4. Внутренние районы 01–08
Проблема: залиты как суша, и непонятно, о каких водоёмах речь.
- **Стили (без новых данных)**: внутренние районы — штриховка или точечный узор `navy` 20% поверх суши вместо сплошной заливки; подпись «Внутренние воды · 01 Африка». В списке — отдельная группа «Внутренние воды» с пояснением одной строкой: «Пресные водоёмы континента: озёра, реки, водохранилища».
- **Легенда** в углу карты: «Морской район» (сплошная заливка), «Внутренние воды» (штриховка), «Выбрано».
- **Нужны географические данные**: контуры крупных озёр и рек (например, слой Natural Earth lakes/rivers в той же проекции и масштабе). Без них линии воды не рисовать — нарисованные «на глаз» реки будут ошибочными. До появления слоя ориентир — только подпись и штриховка.
- **Код 07**: исторический район (бывший СССР), отдельного полигона на карте нет и рисовать его нельзя. В списке строка «07 · Исторический код, на карте не показан», выбрать можно только при редактировании старой записи, где он уже стоит (для новых — решает владелец). На карте при выборе 07 — плашка «Этот код не отображается на карте», без подсветки чужих полигонов.

## 6. Клавиатура и доступность
- Список — `listbox` с переходом стрелками, Home/End и поиском по вводу номера; Enter выбирает, Esc закрывает окно и возвращает фокус на поле «Район ФАО».
- Полигоны на карте недоступны с клавиатуры (это дублирует список), но доступны для экранных читалок только через список; у SVG `aria-hidden` или краткое описание.
- Цели касания на карте у мелких районов: на mobile выбор через список обязателен, на карте — увеличение.

## 7. Проверяемые критерии
1. При 1280×800 и 1440×900 под картой нет пустой полосы больше 24px другого цвета, чем океан.
2. Выбранная строка: контраст текста ≥ 4.5:1, есть галочка и `aria-selected`.
3. Наведение на строку подсвечивает полигон и наоборот.
4. Внутренние районы отличаются от морских без опоры на цвет (штриховка + легенда).
5. Для 07 нет подсвеченного полигона и есть подпись «на карте не показан».
6. На 390px `scrollWidth === clientWidth`, кнопки ≥ 44px, «Выбрать» видна при прокрутке списка.
7. Весь выбор работает только с клавиатуры, Esc возвращает фокус.

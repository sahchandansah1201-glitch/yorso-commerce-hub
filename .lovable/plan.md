# Заметки в карточках Контакта, Компании и Сделки — обсуждение оформления

Только обсуждение. Файлы не менялись, макет не создавался, это не приёмка владельцем. Доработка предполагается внутри существующих карточек YORSO, оформление и типографика проекта сохраняются, интерфейс светлый.

## Оценка компоновки

**Список заметок в карточке**

- Оставить плотный список: заголовок в одну строку, под ним первая строка текста, справа дата изменения (или дата создания, если изменений не было) и автор. Строка 56–64 px, вложения — значок с числом, связанные записи — не более двух названий и «+N».
- Кнопка «Добавить заметку» в шапке раздела, обычным регистром, без второй кнопки внизу списка.
- Сортировка по дате изменения, новые сверху.

**Окно заметки**

- Согласен с окном внутри карточки: ширина 720–768 px, тело прокручивается, «Сохранить» и «Отмена» закреплены снизу и всегда видны, включая 390 px. На телефоне окно занимает почти всю высоту.
- Порядок в теле: заголовок → текст → связанные записи → вложения → сведения о создании и изменении → история событий (свёрнута).
- Заголовок — отдельное поле в одну строку, не первая строка текста. Иначе список останется без опоры.
- Просмотр и редактирование — одно окно с кнопкой «Редактировать»; при незакрытом редактировании закрытие спрашивает подтверждение, иначе текст теряется.

**Панель форматирования**

- Компактная панель значками Lucide в один ряд: жирный, курсив, список, нумерованный список, ссылка. Каждому значку — подсказка и подпись для чтения с экрана, область нажатия ≥44×44 px на телефоне.
- Ссылка — небольшое окно с двумя полями (текст, адрес); вставка адреса без проверки существования страницы.
- Панель показывается только в режиме редактирования и не «залипает» поверх текста.

**Связанные записи и вложения**

- Связанные записи — привычный выпадающий список с поиском и множественным выбором: оранжевый фокус, голубой выбор. Выбранное показывать компактными метками с крестиком, не второй карточкой.
- Вложения — простая строка «имя · размер», справа «Скачать» и «Удалить». Удаление — с подтверждением. Заметка хранит свои вложения, они не смешиваются с документами компании.

**Старые заметки**

- Ключевое ограничение: без заголовка показывать первую строку текста как подпись и не подставлять придуманный заголовок; без даты изменения показывать только дату создания и не приравнивать её к изменению; при неизвестном авторе — «Автор не указан». В истории событий такие пропуски просто отсутствуют, а не «восстанавливаются».

**Время**

- Дата и время везде в одном формате с часами и минутами, часовой пояс один и подписан один раз в разделе истории, чтобы не повторять его в каждой строке.

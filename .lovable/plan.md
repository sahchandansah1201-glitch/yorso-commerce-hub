# Профиль поставщика: язык в адресе, canonical, hreflang и тест файлов

Что я проверил на самом деле: прочитал присланный текст и показанные в этом чате файлы (`src/lib/seo.ts`, `LanguageContext.tsx`, `SupplierProfile.meta.test.tsx`). Ваш сайт я не открывал и тесты не запускал.

## Вердикт
`?lang=ru|en|es` подходит. Google разрешает различать языковые версии параметром адреса, если у каждой версии свой адрес и ссылки на версии взаимные. Ниже 7 критичных условий.

## Критичные условия

**1. Адрес без `lang` не должен давать разный язык на одном адресе.** Сейчас `/suppliers/:id` показывает язык из сохранённых настроек. Если на нём стоит canonical на `?lang=ru`, а страница показывает EN, сигналы противоречат друг другу. Решение: при открытии без `lang` сразу заменить адрес (`replace`, без новой записи в истории) на `?lang=<выбранный язык>`. Canonical всегда соответствует языку, который показан.

**2. Порядок выбора языка.** Корректный `lang` в адресе > сохранённый выбор > язык браузера > RU. Язык из адреса записать в сохранённые настройки, чтобы на других страницах он не менялся. Неверное значение (`?lang=de`, `?lang=<script>`) не показывать на странице и сразу заменить на выбранный язык.

**3. Переключатель языка обновляет адрес.** Смена языка = `navigate(..., { replace: true })` с новым `lang`, остальные параметры не терять. При «назад/вперёд» и перезагрузке язык берётся из адреса, а не из сохранённых настроек. Иначе «назад» покажет адрес `?lang=en` с русским текстом.

**4. Canonical и alternate — только из проверенных частей.** `origin + /suppliers/ + encodeURIComponent(id) + ?lang=xx`. Без `q`, `page`, меток рекламы, `#`. Набор: `ru`, `en`, `es` и `x-default` → тот же адрес, что `ru`. Это допустимо: `x-default` может совпадать с одной из версий.

**5. Приватность.** Заголовок страницы, description, og и twitter всегда используют скрытое имя поставщика, даже если у пользователя есть доступ к ценам. Иначе раскрытое имя попадает в превью при отправке ссылки. В адресах и метаданных только ID поставщика.

**6. Очистка при уходе и ошибках.** На 404, ошибке загрузки и при уходе со страницы: удалить canonical, все `link[rel=alternate][hreflang]`, вернуть общие title и description (`restoreGlobalSeo`). На 404 и ошибке добавить `meta name="robots" content="noindex"` и удалить его при уходе. В `seo.ts` нужна функция удаления alternate — сейчас её нет.

**7. Метаданные ставятся после данных.** Сначала загрузить поставщика, затем ставить canonical и hreflang. Пока данные загружаются, ссылок нет — иначе ошибка оставит ссылки на несуществующую страницу. Ответ для старого ID после перехода на новый игнорировать.

## Тест файлов (IndexedDB)
- Только настоящий браузер (Playwright), без флагов окружения и без `skip`. Если браузера нет, тест падает с понятной ошибкой «Не найден браузер Playwright».
- Два файла с известными байтами (не только размер): сравнить хеш SHA-256 до и после.
- Шаги: сохранить → сменить ID публикации → перезагрузить → опубликовать ещё раз → прервать запись (закрыть страницу во время записи или `transaction.abort()`) → перезагрузить. Ожидание: оба прежних файла на месте, байты совпадают, прерванный файл не появился наполовину.

## Минимальные тесты SEO
1. Сохранён EN, открыт `?lang=es` → страница ES, `html lang="es"`, canonical `?lang=es`.
2. Открыт адрес без `lang` → адрес заменён на `?lang=<язык>`, в истории одна запись.
3. 4 alternate (ru, en, es, x-default), каждый открывает свой язык в чистом браузере без сохранённых настроек.
4. `q`, `page`, `#`, `utm_*` не попадают в canonical и alternate.
5. Гость и пользователь с доступом: в title, description, og нет раскрытого имени.
6. 404 и ошибка загрузки: нет canonical и alternate, есть noindex. После перехода на другую страницу noindex удалён.
7. Смена языка → «назад» → «вперёд» → перезагрузка: язык совпадает с адресом каждый раз.

## Компромиссы
- Ссылки сайта без `lang` будут один раз заменять адрес. Это незаметно, но в аналитике появятся адреса с `lang`.
- Сайт отрисовывается в браузере. Поисковик увидит canonical и hreflang только после выполнения скриптов. Без серверной отрисовки это ограничение остаётся.
- Остальные страницы пока без `lang`: в этой задаче не расширять.

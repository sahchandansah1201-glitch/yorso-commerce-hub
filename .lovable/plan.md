# Вариант 4 «Качество»: схема и критическая проверка

Это дизайн по описанию. Сайт я не открывал. Следующий раунд оцениваю только по вашим снимкам.

## Проверка размеров
- 701,77 × 0,85 = 596,50. Сумма 596,50 + 715,49 = 1311,99 = прежняя ширина. Расчёт верный.
- 390: фото 326px шириной, высота по соотношению сторон, не меньше прежней.

## Названия
RU «Качество» · EN «Quality» · ES «Calidad» — подходят.

## Схема 1440 (2 колонки)
```text
[Галерея 596.5]   | Правая колонка 715.5
                  | 1. Идентичность
                  |    H1 28/36 (2 строки максимум)
                  |    Научное название 16/24 курсив
                  |    Строка 16/24: Скумбрия · HGT · Мороженая · 50+
                  | 2. Сетка качества 3 × 2, без рамок, разделитель сверху
                  |    Район FAO | Заморозка | Глазурь
                  |    Произведено | Годен до | Хранение
                  |    подпись 14/20 приглушённая, значение 16/24, 600
                  | 3. Поставка: строка «FOB · порт Нинбо · Мин. партия 24 т»
                  |    Цена или строка доступа 14/20
                  |    [Запросить цены]  Поставщик: Норвегия
```
Почему так: значения качества короткие (FAO 61, BQF, 3%, 09.2026). Их удобно сравнивать глазом по сетке, ячейка ~225px вмещает их без переноса. Длинная разделка остаётся в строке идентичности, где у неё вся ширина колонки.

**Как отличается путь взгляда:** в «Паспорте» взгляд идёт сверху вниз по таблице «подпись — значение». В «Качестве» — по горизонтальной сетке из 6 коротких значений, затем одна строка поставки. Отличие задаёт сама сетка, а не карточки или поясняющий текст.

## Схема 390
```text
H1 24/32 → научное → строка идентичности (переносится)
Фото 326px
Сетка качества 2 × 3 (ячейка ~155px)
Поставка → цена/доступ → [Кнопка 48px]
Полная спецификация (открыта) → FAQ
```

## Правила данных
- Только непустые поля публичных данных. Пустая ячейка не показывается; если заполнено меньше 3, сетка убирается, и вариант ведёт себя как «Паспорт».
- «Хранение»: показывать как есть: «-18». Не дописывать «°C». В кабинете продавца — подсказка «Укажите единицу температуры».
- Даты: «09.2026».
- Заголовок сетки не нужен. Не писать «Проверено», «Качество подтверждено». Фото рядом — это фото продавца, не проверка.
- Полная спецификация ниже остаётся открытой и полной. Повтор 6 полей сверху допустим: это обзор, а таблица — полный источник.

## Критика выбора
1. **Кнопка может уйти ниже первого экрана.** Оценка высоты правой колонки при ваших минимальных шрифтах: идентичность ~150px, сетка ~120px, поставка с кнопкой ~200px, итого ~470px. Над колонкой сейчас ~290px (шапка, переключатель вариантов, «Назад», крошки). Кнопка окажется около 760–800px — на экране 1440×900 это на границе. Решение: убрать дубль «Назад в панель закупок» (крошки уже есть) — это ~50px. Критерий на снимке: низ кнопки выше 900px.
2. **Качество раньше коммерции — для закупщика это обратный порядок.** Подходит технологу и закупщику свежих партий. Для товара без данных о качестве вариант бесполезен — поэтому правило «меньше 3 полей → Паспорт».
3. **Смысл «качества» можно прочитать как оценку.** Слово «Качество» есть только в названии варианта для сравнения, не на странице для покупателя.
4. **«Хранение -18» без единицы** в сетке заметнее, чем в таблице. Это повод сообщить продавцу, но не исправлять.
5. **Повтор с «Паспортом».** Если на снимках 1 и 4 будут выглядеть одинаково, отличие — только сетка 3 × 2. Если она станет таблицей — вариант не нужен.

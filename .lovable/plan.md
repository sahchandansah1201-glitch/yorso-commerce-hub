# Консультация: видимость выбранного района ФАО в окне выбора на карте

Это только консультация. Код, страницы и настройки не менялись, локальный стенд не проверялся.

## Оценка предложения
Предложение верное. Три уточнения:
1. Строка статуса: одна строка высотой 40–44 px сразу под заголовком, над картой и списком. Фон светло-голубой (тот же оттенок, что у выбранной строки), слева тонкая оранжевая полоса — как у строки списка, так их легко связать взглядом. Код района жирным в моноширинных цифрах (`FAO 61`), затем полное название обычным начертанием. На 390px название переносится на вторую строку, без обрезки многоточием.
2. Прокрутка: только `scrollIntoView({ block: "nearest" })` внутри контейнера списка, без плавной анимации при открытии окна и с плавной при клике на карте. Если `prefers-reduced-motion`, всегда мгновенно. Фокус не переносим; объявление для экранных чтецов делает строка статуса (`aria-live="polite"`, только при смене выбора, не при открытии).
3. Поиск: выбор на карте очищает фильтр, только если выбранная строка под него не попадает. Если попадает — запрос оставляем, чтобы не терять ввод пользователя.

## Минимальные улучшения для быстрого сканирования
- В строке списка код района вынести влево колонкой фиксированной ширины (`01`…`88`), название справа — глаз ищет по коду.
- Внутренние районы 01–08 отделить от морских тонким подзаголовком «Внутренние воды» / «Моря и океаны», без новых карточек.
- Историческому коду 07 не давать полигон на карте; в списке подпись «нет на карте».
- Наведение на карте: только подсветка района и всплывающая подпись кода; строка статуса не меняется.
- Пустой выбор: строка статуса показывает «Район не выбран» приглушённым цветом той же высоты — ничего не прыгает.

## 390px
- Порядок сверху вниз: заголовок, строка статуса, карта (не выше ~35% высоты экрана), поиск, список, кнопки.
- Строка статуса закреплена под заголовком, список прокручивается сам; кнопки «Готово/Отмена» закреплены внизу, не перекрывают последнюю строку (отступ снизу у списка = высота панели кнопок).
- При открытой клавиатуре (поиск) карта может уезжать вверх, строка статуса остаётся видимой.
- Все цели 44 px, ширина документа не больше экрана.

## Проверки UX
1. Клик по району 61 на карте при списке вверху: строка 61 видна в списке, страница и окно не сдвинулись, фокус остался на карте.
2. Открыть окно с уже выбранным 61 (без сети): строка видна сразу, без анимации, статус показывает код и название.
3. Ввести «08», кликнуть 61 на карте: фильтр очищен, строка 61 видна.
4. Наведение на район 27 без клика: статус по-прежнему «ФАО 61».
5. Только клавиатура: Tab по списку, Enter выбирает, видна оранжевая обводка фокуса; Escape и X закрывают окно, фокус возвращается на кнопку открытия.
6. 390px: статус виден при открытой клавиатуре, нет горизонтальной прокрутки, последняя строка не скрыта под кнопками.

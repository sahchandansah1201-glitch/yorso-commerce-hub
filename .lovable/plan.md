# Аудит профиля поставщика (/suppliers/:id) — независимая позиция

Только аудит. Код, сборка, синхронизация и публикация не входят. Описание текущего состояния взято из вашего брифа (локальный гостевой профиль, 10 тестовых товаров). Сам я его не проверял.

## Главная находка
Во вкладке «О компании» значения по умолчанию выглядят как заявления компании: 0 т, 0 линий, около 0 сотрудников, FCA, MOQ 0, 0–0 дней, TBC. Для покупателя это хуже пустого поля: он видит то ли фейк, то ли сломанную страницу (тема «поддельные компании» из S1). Нужно исправить в первую очередь.

## Порядок просмотра
- **За 5 секунд:** маскированное имя, страна, тип только при проверенном источнике, год основания; затем 4 фото (3 на телефоне); затем одно главное действие.
- **За 30 секунд:** каталог (товар, происхождение, Incoterm, MOQ, цена закрыта); коды сертификатов с источником; документы со статусом; видео и отгрузки как дополнительные материалы.
- **Главное действие:** гость — «Создать аккаунт покупателя»; участник — «Запросить доступ к цене»; с доступом — «Подготовить запрос» (OfferInquiryDialog). На каждом экране одна такая кнопка, без повторов.

## L1–L8

**L1. Значения по умолчанию не выдаём за факты (P1)**
- Потребность: понять реальную мощность и условия. Факт: сейчас значения подставлены по умолчанию.
- Изменение: показывать поле, только если оно получено от компании. Иначе строка «Не указано» (`fallback` / `account_value_notSpecified`). Нули и FCA по умолчанию убрать.
- Повторное использование: шаблон `Field` или `fallback` в разделе «О компании».
- Риск: в хелперах локального предпросмотра (`localPreview*Facts`) значения генерируются из хэша. В интерфейсе такие значения не показывать как заявленные.
- Приёмка: в профиле без данных нет ни одного «0 т» или «0–0», нет FCA, если у товаров FOB, CFR или EXW.

**L2. Условия поставки берём из реальных товаров**
- Потребность: какие Incoterms реально доступны. Факт: у товаров FOB, CFR и EXW, а в «О компании» стоит FCA.
- Изменение: список Incoterms и диапазон MOQ собирать из товаров каталога с подписью «По товарам каталога».
- Без новых методов сервера.
- Приёмка: Incoterms в «О компании» совпадают с объединением Incoterms товаров каталога.

**L3. Шапка как в строке каталога поставщиков**
- Повторное использование: шапка ProcurementSupplierRow (имя по маске, флаг, страна, «Основана в {year}», «Сохранить»).
- Тип «Трейдер» показываем только при проверенном источнике, иначе убираем (как в принятом решении R4).
- В шапке одно действие доступа. Копирование ссылки — значок с aria-label.
- Телефон 390: имя переносится, а не обрезается.

**L4. Три состояния с разным текстом**
Блоки: документы, описание, видео, отгрузки.
- **Пусто** — «Компания не добавила».
- **Закрыто** — «Откроется после доступа к цене». Значок замка только здесь.
- **Ошибка** — «Не удалось загрузить» и кнопка «Повторить».

Источник: SupplierEvidenceSections (поля scope, issuer, reference, source, check state, date, error, closed). Приёмка: для каждого блока сделать снимки трёх состояний, тексты должны отличаться.

**L5. Сертификаты: код не равен проверке**
- Повторное использование: SupplierCertificationSummary, разделённый на группы «Компания и производство» и «Товары», CertificationDeclarations.
- Подпись: «Источник: заявление компании», статус проверки отдельно. Слово «Проверено» допустимо только при наличии издателя, номера и даты.
- Доступ к цене не открывает закрытые документы, доступ к ним отдельный.
- Приёмка: в разметке нет «verified» без даты проверки.

**L6. Каталог остаётся вкладкой по умолчанию**
- Повторное использование: CatalogOfferRow / MobileOfferCard, флажки у товаров, «Подготовить запрос».
- Вкладка хранится в URL (`?tab=`), чтобы восстанавливаться после перезагрузки и кнопки «Назад». Сейчас это требует проверки.
- Блок «Мои закупки» опустить ниже каталога или свернуть: он мешает первому просмотру.
- Телефон: панель выбранных товаров закреплена внизу, кнопки не меньше 44 px.

**L7. Видео и отгрузки — дополнительные материалы**
- Подписи: «Видео от компании» (это не аудит), «Отгрузка по данным компании» (это не подтверждение покупателя).
- Повторное использование: GalleryVideo, Accordion. Если данных нет, вкладку скрыть или показать «Компания не добавила», а не пустой экран.

**L8. Запрос и ответы**
- Повторное использование: OfferInquiryDialog, реальный запрос (RFQ) и ответы.
- Гость: одна кнопка «Создать аккаунт покупателя», без повторов на каждой вкладке.
- Участник: запрос доступа к цене не открывает документы. Это нужно прямо сказать в тексте.
- Финансовых гарантий и защиты предоплаты не обещаем.

## Сомнения
- Скрывать пустые вкладки «Видео» и «Отгрузки» или показывать их с пометкой «Не добавлено»? Скрытие убирает шум, пометка честнее. Я за пометку внутри вкладки «О компании», без отдельных пустых вкладок.

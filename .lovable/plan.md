# «Сертификаты и допуски»: дизайн для локального внедрения

Это совет для Codex. Я смотрел только файлы, показанные в этом чате (`CertificationBadges.tsx`, прошлый план P1S, `supplier-documents.ts`). Ваш текущий код может отличаться. Сайт не открывал.

## 0. Главные правила
1. **Заявление ≠ проверка.** Выбор в редакторе = «Заявлено». Зелёной галочки и слова «Проверено» нет, пока нет реальной проверки YORSO.
2. **Документ отдельно.** Загруженный документ = «Документ есть». Он закрыт по текущим правам, как сейчас в SupplierEvidenceManager.
3. **Область действия.** Сертификат относится к компании, предприятию или товару. MSC/ASC компании не значит, что этот товар MSC: для товара нужна цепочка поставок (CoC).
4. **Не путать типы.** FDA, EFSA, CNCA, AQSIQ (сейчас GACC) — ведомства, а не сертификаты. Номер допуска ЕС и регистрация FDA — регистрации предприятия. EAC — знак соответствия для конкретной продукции, а не сертификат компании. Ветеринарный сертификат и сертификат улова — документы партии, не сертификат компании.
5. **Без утечки имени.** Пока у покупателя нет доступа к поставщику: показывать только код и статус. Номер сертификата, ссылка на реестр, файл, название органа сертификации не показываются — по номеру в реестре MSC/ASC/BRCGS легко найти компанию.

## 1. Справочник с группами (поиск по коду и названию)
| Группа RU / EN / ES | Коды |
|---|---|
| Безопасность пищевых продуктов / Food safety / Seguridad alimentaria | HACCP, BRCGS (сейчас BRC), IFS, FSSC 22000, ISO 22000 |
| Устойчивость / Sustainability / Sostenibilidad | MSC, ASC, GLOBALG.A.P., Friend of the Sea (FOS) |
| Религиозные / Religious / Religiosas | Halal, Kosher |
| Допуски рынков / Market approvals / Autorizaciones de mercado | Допуск ЕС (номер предприятия) — код EU |

Существующие выбранные значения сохраняются. Код `BRC` показывать как «BRCGS», хранить как есть. Неизвестные старые строки (BAP, «EU Health Mark») — группа «Другие / Other / Otros», видны и удаляются. Новые коды (FSSC 22000, BAP, регистрация FDA, GACC) — только после решения владельца; без них справочник работает.

| Админ | Список документов с кодом, областью, сроком; статус проверки — только если процесс реально есть | — |

Без полос «Сертифицировано», без логотипов во всю ширину.

## 4. Крайние случаи и доступность
- MSC у компании, но товар не из CoC → «MSC · Компания», не «MSC · Этот товар». В карточке товара код MSC не выделять как свойство товара.
- Срок истёк → «Срок истёк» показывать; код из фильтра «Сертифицировано» не убирать молча, но и не считать действующим.
- Дубли: «BRC» и «BRCGS», «IFS Food» и «IFS» — один код (канонизация из P1S).
- Редкая комбинация кодов может косвенно указать на поставщика — остаточный риск, принять или скрыть на уровне владельца.
- Поиск: `role="combobox"`, стрелки, Enter, Escape; выбранные строки с кнопкой удаления 44px, `aria-label="Удалить MSC"`.
- 390: строка переносится, без горизонтальной прокрутки; группы — заголовки `h3`, не карточки.
- Статус не только цветом: всегда текст.

## Сравнение вариантов
| | A. Одна типографская плитка для всех 29 | B. 3 логотипа (MSC, ASC, BRC) + плитки для 26 |
|---|---|---|
| Узнаваемость | По привычной аббревиатуре | Логотипы узнаются лучше, остальные хуже |
| Права | Логотипы не нужны | Знак MSC/ASC на товаре требует лицензии; логотип выглядит как маркировка товара |
| Смысл | Не похоже на печать проверки | Логотип читается как «сертифицировано», хотя это заявление |
| Единообразие | Один вид | Два вида рядом |
| Сложность | Один компонент, одна таблица | Два пути отображения, файлы логотипов |

**Выбор: A.** Проще, без вопросов лицензии и без ложного «проверено». Текущие логотипы MSC/ASC/BRC убрать из выбора и карточек.

## Знак: три размера
| Размер | Где | Вид | Текст в знаке |
|---|---|---|---|
| S | Карточки (главная, /offers), сравнение, каталог поставщиков | Чип без плитки: рамка `border-border`, фон `bg-muted/50`, высота 24, `px-2`, `rounded` | 12/16, 600, одна строка, только короткая метка |
| M | Профиль поставщика, Паспорт, «Сертификаты и допуски» в кабинете, выбор | Плитка 36×36 `rounded-md` + название 16px справа | 1 строка: 11/14, 700; 2 строки: 10/12, 700 |
| L | Диалог сведений | Плитка 56×56 | 1 строка: 16/20; 2 строки: 13/16 |

- Цвет: `bg-muted`, `text-foreground`, `border-border`. Контраст ≥ 4,5:1. Без зелёного, без галочек.
- Плитка `aria-hidden`: рядом всегда видно название. В S метка — сам текст, у чипа `title` и в диалоге полное название.
- Меньше 10px не использовать (сейчас 9px — убрать).
- Строка не больше 5 знаков; длинное — в 2 строки по таблице ниже. Межбуквенный интервал 0.
- Интерактивный знак (S вне ссылки, M) — кнопка 44×44 с видимым фокусом; внутри ссылки карточки — не интерактивный.

## Размещение
- Карточки: до 3 чипов S + «+N». Порядок — по каталогу.
- Профиль поставщика и кабинет: M по группам, один статус «Заявлено компанией» над списком.
- Паспорт: строка «Сертификаты и допуски» — чипы S в одну строку с переносом; область «Компания», если товарной области нет.
- Диалог: L-плитка, полное название, группа, описание, «Это заявление компании».

# Ошибка публикации из-за закрытых данных в публичном тексте: проверка подхода и тексты

Я не открывал ваш локальный сайт и ничего не тестировал. Разбор основан только на вашем описании. Код не менял.

## Вердикт: одобряю с 5 условиями

1. **Отдельная ошибка, без общей фразы.** Ответ `offer_publication_private_text` не превращать в «Проверьте обязательные поля». Все поля заполнены, поэтому эта фраза ведёт пользователя не туда.
2. **Ошибка у конкретного поля.** Если сервер не указал поле, не угадывать его. Показать ошибку над списком ошибок и дать общую ссылку «Описание и публичные поля». Подсвечивать найденный фрагмент можно, только если сервер вернул его место.
3. **Список ошибок и фокус.** Список ошибок стоит над кнопкой. У каждого пункта есть ссылка на поле. Фокус переходит на первое поле с ошибкой, поле прокручивается в видимую область. У поля `aria-invalid="true"` и `aria-describedby` указывает на текст ошибки. Список объявляется через `role="alert"` один раз, без повтора при каждом нажатии клавиши.
4. **Проверка до загрузки медиа.** Проверить текст до загрузки файлов, чтобы файлы не загружались зря. Ошибка медиа показывается отдельно и не помечает текстовые поля.
5. **Черновик и текст.** Черновик сохраняется. Текст не изменяется и не удаляется сам. Ошибка снимается после изменения поля или после новой проверки сервером. Пока сервер не подтвердил, не показывать «исправлено».

Риск: перенесённое описание со ссылкой на источник. Пользователь может подумать, что ссылку на источник оставлять можно. Текст ошибки должен прямо называть ссылки.

## Тексты

**1. Ссылка или email в публичном тексте**
- RU: «Удалите ссылки и email из этого поля. Покупатель видит этот текст до доступа к поставщику.»
- EN: «Remove links and email addresses from this field. Buyers see this text before supplier access.»
- ES: «Quite los enlaces y correos de este campo. El comprador ve este texto antes del acceso al proveedor.»

**2. Название поставщика в публичном тексте**
- RU: «Удалите название компании из этого поля. Название видно только после доступа к ценам.»
- EN: «Remove the company name from this field. The name is visible only after price access.»
- ES: «Quite el nombre de la empresa de este campo. El nombre solo es visible tras el acceso a precios.»

**3. Неизвестный отказ медиа (422)**
- RU: «Файл не принят. Поля заполнены правильно. Загрузите файл ещё раз или выберите другой.»
- EN: «The file was not accepted. Your fields are correct. Upload the file again or choose another file.»
- ES: «El archivo no se aceptó. Los campos son correctos. Vuelva a subir el archivo o elija otro.»

Пункт списка ошибок (ссылка): RU «Описание: удалите ссылки и email» · EN «Description: remove links and email» · ES «Descripción: quite enlaces y correos».

В текстах нет обещания удалить сохранённые ссылки и нет предложения отключить проверку.

## Что проверить вручную
- Перенесённое описание со ссылкой → ошибка у «Описание», фокус на поле, текст на месте, файлы не загружались.
- Удалить ссылку → публикация проходит; после перезагрузки черновик совпадает.
- Отказ файла 422 → текстовые поля без красной рамки.
- 390px: текст ошибки переносится, нет горизонтальной прокрутки, ссылки в списке не меньше 44px, фокус виден; ES не обрезается.

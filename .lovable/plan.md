# Консультация: «Моя компания → Товары» (wireframe)

Это совет для реализации. Проект, данные и сборка не менялись, авторизация и база не подключаются, новые поля не добавляются. «Ассортимент» (покупаем/продаём) остаётся отдельным разделом без цен.

## 1. Список товаров (desktop)

```text
Моя компания › Товары                                   [+ Создать товар]
┌─[ Все 24 ]┐ Опубликованы 12   Черновики 9   Скрыты 3
┘          └──────────────────────────────────────────────────────────
│ [Поиск по названию или латинскому…   (лупа)] [Состояние v] [Сорт.: Изменено v] │
│ Найдено 24 · сбросить                                               │
│──────────────────────────────────────────────────────────────────────│
│ ▢ Атлантический лосось       Охлаждённый · Филе   от 9,40 $/kg  Опубл.  12.09  ⋯ │
│   Salmo salar                MOQ 1 t              3 условия              │
│──────────────────────────────────────────────────────────────────────│
│ ...                                                       ‹ 1 2 3 ›  │
└──────────────────────────────────────────────────────────────────────┘
```
- Строка 56px: название и латинское название · состояние и вид разделки · «от» цены по условию по умолчанию + «N условий» · статус текстом с точкой (не оранжевым) · дата изменения · меню «⋯» (Изменить, Скрыть/Опубликовать, Дублировать).
- Цены в разных валютах не суммируются; в строке показывается только валюта условия по умолчанию.
- Ошибка загрузки: строка «Список не загрузился · Повторить», не пустое состояние.

## 2. Список (mobile 390px)

```text
Товары                       [+]
[Все 24][Опубл. 12][Черн. 9] →   (горизонтальная прокрутка)
[Поиск…                (лупа)]
[Фильтры (1)]  [Изменено v]
──────────────────────────────
Атлантический лосось       ⋯
Salmo salar
Охлаждённый · от 9,40 $/kg
Опубликован · 12.09
──────────────────────────────
```
Запись около 112px, «⋯» 44×44, фильтры открываются нижней панелью с кнопкой «Применить».

## 3. Карточка товара (desktop)

```text
‹ Товары   Атлантический лосось · Черновик · Изменено 12.09 14:20
┌──────────────┬───────────────────────────────────────┬──────────────┐
│ Разделы      │ Товар                                 │ Предпросмотр │
│ ● Товар    ✓ │  Коммерческое название*  [         ]  │ (строка как  │
│ ○ Происх.  2!│  Латинское название*     [        v]  │  в каталоге, │
│ ○ Характ.    │  ...                                  │  локально)   │
│ ○ Фото       │ ─────────────────────────────────────  │              │
│ ○ Продажа  ✓ │ Происхождение и сроки                 │ Готовность   │
│ ○ Условия  1!│  ...                                  │ 4 из 6       │
├──────────────┴───────────────────────────────────────┴──────────────┤
│ Не сохранено · 2 ошибки       [Отмена] [Сохранить черновик] [Опубликовать] │
└──────────────────────────────────────────────────────────────────────┘
```
- Одна длинная форма, разбитая на 6 секций с заголовками h3, а не на скрытые вкладки: всё доступно поиском Ctrl+F, ничего не теряется. Слева оглавление (sticky), активный пункт подсвечивается при прокрутке; у пункта — галочка «заполнено» или число ошибок.
- Оглавление визуально соединено с областью: активный пункт имеет фон `card` и левую полосу primary 2px, без заливки. Если всё же нужны вкладки — активная вкладка того же фона, что и панель, без нижней границы, полоса primary 2px сверху.
- Справа (≥1280px) — колонка 280px «Предпросмотр»: как строка будет выглядеть в каталоге для покупателя, с подписью «Предпросмотр, не опубликовано». На 1024–1279px предпросмотр открывается кнопкой в нижней панели.

## 4. Секция «Условия поставки и цены»

```text
Единица* [kg v]   MOQ* [ 1 000 ]        (один на товар)
Условия поставки                                   [+ Добавить условие]
│ ★ FOB · Bergen, Norway · EUR · 3 ступени · от 9,40 €   [Изменить] ⋯ │
│   CIF · Rotterdam · USD · 1 ступень · 10,20 $          [Изменить] ⋯ │
```
- Каждое условие — одна строка; правка во вкладной панели справа (на mobile — полноэкранный слой) с фиксированными шапкой и кнопками.
- Внутри: Incoterms*, место*, валюта* (USD/EUR/CNY/RUB, CrmSelect), ступени «Объём от · Цена» мини-таблицей. Первая ступень ≥ MOQ, объёмы растут; ошибка показывается у конкретной строки.
- В списке условий нет общего итога.

## 5. Mobile-карточка

```text
‹ Атлантический лосось   Черновик
[Товар ✓][Происх. 2!][Характ.]→     (sticky-полоса разделов, прокрутка)
Товар
 Коммерческое название*
 [                       ]
 ...
──────────────────────────────
[Предпросмотр]  [Сохранить черновик]   (sticky-панель, 56px)
                 [⋯ Опубликовать]
```
- Полоса разделов под шапкой — якоря на секции, активный подсвечивается.
- Поля в одну колонку, пары (Единица + MOQ, Объём + Цена) в две.

## 6. Закреплённые действия без перекрытия
- Нижняя панель `sticky bottom-0` внутри области формы, а не `fixed` к окну; у формы снизу запас под высоту панели (`pb-[панель+16px]`).
- При фокусе на поле — `scrollIntoView({block:"center"})` с учётом `scroll-margin-bottom`, равного высоте панели; на mobile используется `visualViewport`, чтобы панель поднималась над клавиатурой или скрывалась, пока клавиатура открыта (решает владелец).
- В панели: состояние «Не сохранено / Сохранение… / Сохранено 14:20 / 2 ошибки» слева (aria-live), кнопки справа. «Опубликовать» — основная оранжевая кнопка, остальные — outline.

## 7. Статусы, ошибки и предпросмотр
- Статус товара — текст с маленькой точкой: Опубликован (success), Черновик (muted), Скрыт (muted с чертой). Оранжевый у статусов не используется.
- Ошибки: у поля текст + `aria-invalid`; в оглавлении — число ошибок; при «Опубликовать» с ошибками фокус переходит на первое ошибочное поле, в панели — «2 ошибки · Показать».
- «Сохранить черновик» не требует обязательных полей; «Опубликовать» требует.
- Предпросмотр строится из текущих значений формы и ничего не отправляет; пустые значения выглядят как «Не указано», не подставляются примерные данные.
- Уход со страницы с несохранёнными правками → «Выйти без сохранения?».

## 8. Проверяемые критерии
1. «Ассортимент» и «Товары» — разные пункты меню, на странице товаров нет матрицы покупаем/продаём.
2. Активная вкладка или пункт оглавления без оранжевой заливки, соединены с областью (нет линии между ними).
3. Строка списка ≤ 60px на компьютере, запись на mobile ≤ 120px.
4. На 390 и 320px `scrollWidth === clientWidth`, элементы управления ≥ 44px.
5. Нижняя панель ни в одном состоянии не закрывает поле в фокусе (проверяется последнее поле каждой секции, с открытой клавиатурой).
6. Число ошибок в оглавлении совпадает с числом полей с `aria-invalid`.
7. Одна пара Единица/MOQ на товар; у условий поставки свои валюта и ступени; общей суммы между валютами нет.
8. Предпросмотр меняется сразу после ввода и подписан как неопубликованный.
9. Весь процесс создания проходит только с клавиатуры; Esc закрывает панель условия и возвращает фокус на «Изменить».
10. Ошибка загрузки не отображается как пустой список.

## 9. Решения владельца
- Какие статусы списка окончательные (Опубликован / Черновик / Скрыт, нужен ли архив).
- Поведение sticky-панели при открытой клавиатуре на mobile: поднимать или скрывать.
- Набор обязательных полей отдельно для каждого состояния продукции.
- Нужен ли предпросмотр на 1024–1279px постоянно или по кнопке.

# Roadmap

## Активные задачи

- [x] P0 — общая основа кликабельного прототипа на скрытом маршруте `/dev/customer-workspace`
      (оболочка, неизменяемый указатель текущей компании — одна активная компания на
      учётную запись, навигация, заголовок раздела, роли, RU/EN/ES, темы,
      библиотека состояний, таблица и карточки 390px). Маршрут регистрируется только
      в dev/test сборке.
- [x] P1 — служебный обзор: готовность возможностей (редакция-кандидат, лицензия не
      согласована, таблица возможностей с ограничением, риском и решением) и обзор доступа
      с нейтральными проверками. Нейтральная недоступность для пользовательских ролей.
- [x] P2 — раздел «Сотрудники» с вкладками «Сотрудники», «Приглашения», «Передача
      владения», матрица прав по действующему договору доступа, диалоги подтверждения,
      закрытый доступ и вход как состояние запрошенного раздела (только в памяти).
      Существующие `/account/employees` и путь приглашения переиспользуются в рабочей
      части позже — прототип их не заменяет.

- [ ] P3 — «Продукция компании» в рабочем пространстве. Не начато.
- [ ] P4 — основная работа с клиентами (компании, контакты, задачи, заметки, связи,
      поиск, фильтры, страницы, удалённые записи). Не начато.
- [ ] P5 — передача и перенос данных. Не начато.
- [ ] P6 — обновление, эксплуатация, восстановление. Не начато.
- [ ] P7 — пилот. Не начато.

## Заморожено

- Frontend-прототипы P0–P7 разрешены текущим поручением владельца и принимаются
  внутренней проверкой по пакетам.
- Backend, API, база, авторизация, хранилище, сеть, деплой и внешние службы — до точной
  итоговой фразы владельца «Интерфейс принят».

## Открытые решения владельца

- Название пользовательского раздела: временно «Работа с клиентами» / Customer work /
  Trabajo con clientes.
- Права Менеджера на удаление, восстановление, экспорт.
- Обозначение унции (OZ = 28,35 г) в объёме.

# Roadmap

## Активные задачи

- [x] P0 — общая основа кликабельного прототипа на скрытом маршруте `/dev/customer-workspace`
      (оболочка, неизменяемый указатель текущей компании — одна активная компания на
      учётную запись, навигация, заголовок раздела, роли, RU/EN/ES, темы,
      библиотека состояний, таблица и карточки 390px). Маршрут регистрируется только
      в dev/test сборке.
- [x] P1 — служебный обзор: готовность возможностей (редакция-кандидат, лицензия не
      согласована, таблица возможностей с ограничением, риском и решением) и обзор доступа
      с нейтральными проверками. Нейтральная недоступность для пользовательских ролей.
- [x] P2 — раздел «Сотрудники» с вкладками «Сотрудники», «Приглашения», «Передача
      владения», матрица прав по действующему договору доступа, диалоги подтверждения,
      закрытый доступ и вход как состояние запрошенного раздела (только в памяти).
      Существующие `/account/employees` и путь приглашения переиспользуются в рабочей
      части позже — прототип их не заменяет.

- [x] P3 — «Продукция компании»: поля Продукт, Состояние, Закупка/Продажа, Месячный объём,
      Единица, Разделка, Состояние записи; единицы кг, г, т, шт., OZ с постоянной строкой
      «1 OZ = 28,35 г» в списке и в предпросмотре редактирования; «Редактировать» только
      у Владельца и Администратора в обычном состоянии, у остальных — компактная отметка
      «Только просмотр»; «Сделать неактивным» с подтверждением, запись остаётся видимой.
- [x] P4 — работа с клиентами: компании, контакты, задачи, заметки, связанные записи,
      единый поиск, фильтры, сортировка, счётчик, страницы «Назад»/«Далее», карточки
      записей с вкладками, «Импорт», «Экспорт» и «Удалённые записи» в меню действий
      списка. Право определяется только сценарием доступа и никогда не выводится из роли.
- [x] P5 — передача данных: полноэкранный мастер из шести шагов, три вложенных
      проверочных источника, сопоставление колонок, предпросмотр, совпадения и
      дубликаты, выполнение, результат и локальный отчёт; служебная вкладка
      «Перенос данных» с повтором по причине.
- [x] P6 — эксплуатация: нейтральное состояние временной недоступности у пользователя;
      служебная вкладка «Эксплуатация» с очередью, оповещениями, готовностью
      обновления, регистром резервных копий, учебным восстановлением двумя разными
      сотрудниками и таблицей целей без достигнутых значений.
- [x] P7 — пилот: компактное уведомление на «Обзоре», помощь и отзыв на этой странице;
      служебная вкладка «Пилот» с обезличенной сводкой и записью решения по причине.

Интерфейс P0–P7 собран для рассмотрения владельцем. Backend остаётся замороженным до
точной фразы владельца «Интерфейс принят». Согласование владельца не получено.

## Заморожено

- Frontend-прототипы P0–P7 разрешены текущим поручением владельца и принимаются
  внутренней проверкой по пакетам.
- Backend, API, база, авторизация, хранилище, сеть, деплой и внешние службы — до точной
  итоговой фразы владельца «Интерфейс принят».

## Открытые решения владельца

- Название пользовательского раздела: временно «Работа с клиентами» / Customer work /
  Trabajo con clientes.
- Права Менеджера на удаление, восстановление, экспорт.
- Обозначение унции (OZ = 28,35 г) в объёме.
